Fishhhhhh (In Development)

    เนื้อเรื่องมีอยู่ว่า"หลังเกิดระเบิดนิวเคลียร์ โลกของเราก็ผ่านไป 248 ปีโลกเราก็เกิดระบบนิเวศใหม่ๆ และสภาพแวดล้อม ดูเหนือจินตนาการก็ปรากฏขึ้น มีการเปลี่ยนแปลงของสิ่งมีชีวิต มนุษย์ได้ส่งหุ่นยนต์ออกสำรวจ จับสิ่งมีชีวิตทางน้ำกลับไปเพื่อกลับไปวิจัย แม้จะเจอกับอันตรายต่างๆ ก็ตาม เราก็ต้องทำภารกิจให้สำเร็จให้ได้"
    และนี่ก็เป็นเกม Final Project ที่พวกผมกำลังทำกันอยู่ ณ ตอนนี้ก็ใกล้เสร็จแล้วแต่ยังไม่ได้อัด Game trailer ออกมาให้ดูเพราะช่วงนี้ค่อนข้างยุ่งต้องจัดสรรเวลาให้ดี เพื่อไม่ให้กระทบต่อการพัฒนาเกมและการเรียน โดยตอนนี้เกมพวกผมก็ได้ทำไปถึง86%แล้ว และจะทำให้เสร็จภายในเดือนตุลาคมนี้ และผมกำลังพยายามพัฒนามันอย่างเต็มที่และออกมาดีที่สุดเพราะพวกผมมี Plan ว่าจะอัพเกมลงใน Steam เพื่อวางขายจึงอยากทำให้ดีที่สุด โดยในโปรเจกต์นี้ผมมีหน้าที่เป็น
- คนทำเอกสารโปรเจกต์
- เป็น Modeling ตัวละคร,ปลา,สิ่งของและบอส รวมถึงการทำ Animationต่างๆภายในเกม รวมถึงการเชื่อม Animation ของ Unity ภายในเกม
- เป็นผู้ช่วย Developer ในส่วนของ การทำระบบการซ่อมเรือด้วยระบบย่อยขยะทะเลเป็น Scrap เพื่อนำไปซ่อมเรือ


สิ่งที่กำลังเรียนรู้
- การใช้โปรแกรม Blender และ การทำ Animation ก่อนมา Import เข้าเกม
- การทำ Animation Controller ด้วย Blender(ปกติเคยทำแต่ใน Maya)
- การใช้โปรแกรม Unity โดยเฉพาะเรื่องการเชื่อม Animation
- การใช้โปรแกรม Git ในการทำงานร่วมในกลุ่ม
- การจัดสรรเวลาในการทำงาน

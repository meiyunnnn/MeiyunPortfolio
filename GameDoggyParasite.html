DOGGY PARASITE

Doggy Parasite (2D Action ,Survival Horror,Arcade)


    กดที่นี่เพื่อเข้า -> Source DoggyParasite
    เป็นเกม2D เกมแรกที่ผมได้ทำอย่างจริงจัง ผมอยากลองทำเกมที่เป็น Wave เอาชีวิตรอดไปเรื่อยๆ และเก็บเงินมาอัพเกรดสิ่งของ แต่เนื่องด้วยเวลาที่ไม่ค่อยมีและงานที่ค่อนข้างเยอะในช่วงนั้นผมจึงทำ ได้ไม่เยอะมาก แต่ก็พอใจกับที่ทำออกมาครับ โดยที่ผมได้นำระบบที่เคยลองพัฒนาใน U-Turn มาปรับแต่งให้ เข้ากับเกมของผมครับ โดยสิ่งที่ผมทำไปมีดังนี้
- ระบบInventory
- ระบบการเก็บของ
- ระบบการ Spawn ของ enemy
- ระบบร้านค้าขายอาวุธและยา
- ทำAnimation Sprite ของ Unity
- ระบบ Ads ของ Unity
- ทำ GDD
- หัดใช้ Cinemachine


สิ่งที่ได้เรียนรู้
- การทำ 2D Sprite Animation ใน Unity
- การทำ Ads ใน Unity
- การทำ Wave System ที่เรียก prefab enemy ออกมาใช้
- การทำ Shop System การดึงค่าเงินของตัวละคร มาใช้และคำนวนอย่างถูกต้อง
- การทำ Inventory System ที่เก็บของตามช่องที่กำหนดไว้
- การวางแผนล่วงหน้าและกำหนดเวลาการทำงาน
- ได้รู้วิธีและการวางแผนทำ GDD
- ได้เรียนรู้วิธีการใช้ Cinemachine

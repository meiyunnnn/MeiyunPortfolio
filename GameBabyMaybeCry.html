    เรื่องมีอยู่ว่าเด็กน้อยตื่นขึ้นมากลางดึกพบว่ามีประตูแสงประหลาดเปิดออกมันควรจะเป็นโถงทางเดิน ปกติในนอกประตูนั้นกลับกลายเป็นห้องโถงของบ้านที่เค้าไม่รู้จัก
    โดยเกมนี้ก็เป็นอีก 1 เกมที่ผมตั้งใจทำมากๆทั้ง Animation และ Coding เพราะ มันเป็นเกมที่ทำให้ผมได้เอ็นจอยกับการทำงาน และยังได้ลองทำอะไรใหม่ๆดูเยอะเลยครับ ไหนจะระบบ Agent navigator และ ระบบสิ่งของที่สปอนแล้วต้องดึงค่าเข้าเควส มันยากมากๆๆๆ ที่สุด แต่เพราะความสนุกในการทำงาน ทำให้ผมทำงานกับมันโดยไม่รู้สึกเหนื่อยเลยแม้แต่นิดเดียวเลยครับ โดยเฉพาะตอนที่ผมพยายามทำระบบ ของที่สปอนแล้วต้องดึงค่าเข้าเควสเนี่ย มันยากจริงๆครับ มันดึงเวลาผมเกือบสัปดาห์เลย แต่ผมก็ทำมันสำเร็จนะครับ

- ทำโมเดลตัวละครและผีในเกม
- ทำ Animation Game ของตัวละครทุกตัว
- ทำ Animation Trailer
- จัดแสงภายในเกม(แอบโดนเพื่อนบ่นนิดหน่อยว่ามันมืดไป)

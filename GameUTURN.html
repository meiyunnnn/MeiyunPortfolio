U-TURN (Zombie Survival)

    นี่เป็นโปรเจกต์กลุ่มที่พวกผมทำส่งอาจารย์ครับ ซึ่งอาจารย์ต้องการให้ลองทำเกมของตัวเอง โดยที่พวกผมก็ได้นึกถึงเกมสมัยก่อนที่ผมชอบเล่นอย่าง Unturned จึงทำให้ผมนำเกมนี้มาศึกษาระบบ ซึ่งในจุดที่พวกผมศึกษาจะเป็นระบบของเควสเกม และ ระบบ Inventory ที่ลองนำมาศึกษาและลองใช้กับระบบเกมที่ทำดูครับ โดยชื่อตัวเกมที่พวกผมทำเองก็ล้อเลียนมาจาก Unturnedนี่แหละครับ ซึ่งสิ่งที่ผมได้ทำหลักๆในเกมนี้มี
- ทำ Animation
- ทำระบบการSpawn ของ Zombie
- จัดพื้นที่และตกแต่งฉากในเกม
- ช่วย Dev ทำเควสส่วนอื่น


สิ่งที่ได้เรียนรู้
- การเก็บข้อมูลสิ่งของให้เชื่อมกับเควส
- ระบบการSpawn ของ Zombie
- ระบบAnimation ของ Unity ที่ทำให้ Character เป็น Animation เฉพาะจุด
- ได้ฝึกฝนการทำAnimation ผ่าน Unity แบบเบื้องต้น(ขยับ Bone)
และได้รู้ว่าการทำเกมนั้นไม่ใช่เรื่องง่ายเลยครับ
